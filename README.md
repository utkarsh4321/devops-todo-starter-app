# Code Setup

First fork this repo. This repo only contains the **main** branch. So fork it.

Then clone it on your computer

```git clone <FORK_REPO_URL> .```

```bash
cd backend
```
then run 

```bash
npm i
```
then
```bash
cd ..
```
go to frontend folder

```bash
cd frontend
```
Install all the dependencies

```bash
npm i
```
Follow the blog post for rest of the steps
[Blog](https://dev.to/utkarsh4321/part1-how-to-containerize-a-full-stack-app-react-express-and-mysql-4coi-temp-slug-660007/)
